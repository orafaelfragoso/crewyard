# Getting help

- **Something broken?** Run `crew doctor` first; [docs/doctor.md](docs/doctor.md) explains each check. Then see the [recovery runbooks](docs/incident-recovery/runbooks.md).
- **How do I…?** Start with the [installation guide](docs/installation.md), the [CLI reference](docs/reference/cli.md) and the [MCP host setup](docs/mcp-hosts.md).
- **Found a bug or want a feature?** Open an [issue](https://github.com/orafaelfragoso/crewyard/issues/new/choose).
- **Security problem?** Report it privately as described in [SECURITY.md](SECURITY.md).
